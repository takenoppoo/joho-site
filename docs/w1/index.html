ホーム分野（シラバス）使い方
第1週まとめ単語帳確認テスト思考問題

第1週

単語 20語・確認テスト 40問（3日分）・思考問題 4日分。1週間で1セットです。

1単語帳

最重要20語。意味は赤字で、ボタン1つで隠せます。

ひらく

2確認テスト

基礎と応用の4択。全40問を3日に分けて。解説には図もあります。

ひらく

3思考問題

共通テスト形式を4日分。1日約25分。

ひらく

1週間の進め方（目安）

1日目単語帳（20語を1周）→ 確認テスト1日目
2日目単語帳（赤字をかくして確認）→ 確認テスト2日目
3日目確認テスト3日目 → まちがえた語を単語帳で復習
4日目思考問題1日目
5日目思考問題2日目
6日目思考問題3日目
7日目思考問題4日目 → まちがえた所をまとめて見直し

自分のペースで、日数は増やしてかまいません。
